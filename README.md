# odak-muzik

Çalışma Paneli için küçük bir YouTube oynatıcı sayfası. Panel bilgisayardan dosya olarak açıldığı için YouTube videoları doğrudan oynamıyor (Hata 153); bu sayfa üzerinden oynar.

Kullanım: `https://ardaksam.github.io/odak-muzik/?v=VIDEO_ID` (isteğe bağlı `&list=LISTE_ID`, `&start=SANİYE`). Hiçbir şey saklanmaz.
